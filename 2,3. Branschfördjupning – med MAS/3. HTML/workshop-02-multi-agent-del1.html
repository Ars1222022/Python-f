Python-koppling

En agent är en loop med ett verktyg

Agenten får ett mål, väljer ett verktyg och använder resultatet för att gå vidare. Här är ett litet anrop som ber modellen lämna strukturerad JSON. Nyckeln läses från miljön – aldrig från koden.

import os
from groq import Groq

client = Groq(api_key=os.environ["GROQ_API_KEY"])

response = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[
        {"role": "system",
         "content": "Du är en sökordsexpert. Svara med JSON."},
        {"role": "user",
         "content": "Föreslå 5 svenska och 5 engelska sökord för AI engineer."}
    ],
    response_format={"type": "json_object"},
)

print(response.choices[0].message.content)
  • os.environ läser hemligheten från miljön i stället för att hårdkoda den.
  • messages är samtalet: en systemroll och en användarfråga.
  • response_format ber modellen svara med JSON – men du måste fortfarande validera svaret.
  • Resultatet ligger djupt i response-objektet. Skriv hellre en liten hjälpfunktion än att kopiera sökvägen överallt.

Ta med dig: En agent är inte magi. Det är en kontrollerad loop: tänk → välj verktyg → läs resultat → fortsätt. Varje övergång behöver ett tydligt format och ett rimligt felbeteende.

Vanligt misstag

Att lägga hela uppgiften i en enda prompt. En agent blir inte bättre av att få alla verktyg och allt ansvar. Dela upp, mät och sätt gränser.

Säkert arbetssätt

Nycklar hör hemma i .env eller en säker anslutning – aldrig i notebooken, chatten eller Git. Om en nyckel har delats: återkalla den och skapa en ny.

Begreppsmatchning
  • LLM → Modellen som tolkar text och föreslår nästa steg
  • Verktyg / function calling → En funktion som agenten kan välja att anropa
  • .env → Lokal fil för hemligheter som inte ska i Git
Beslutsövningar
  1. Läge 1: Agent 1 ska lämna sökord till Agent 2. Vad är det bästa kontraktet?
    En JSON-lista med strängar, till exempel ["AI engineer", "ML engineer"]. – Rätt. Ett enkelt, validerbart format gör överlämningen förutsägbar.
  2. Läge 2: JobTech API svarar med ett fel. Vad bör Agent 2 göra?
    Returnera ett tydligt fel eller en tom lista med orsak, så att nästa steg kan hantera det. – Rätt. Ett kontrollerat fel är bättre än en krasch utan sammanhang.
  3. Läge 3: Du vill testa Agent 1 utan att göra ett riktigt API-anrop. Vad är klokast?
    Spara ett litet exempelsvar och kör agentens parsning mot det. – Rätt. Då testar du kontraktet snabbt och slipper betala eller vänta på nätet.
Grupparbete – lärarmodell
Ett starkt gruppsvar har ett litet schema, till exempel {"keywords": ["AI engineer", "ML engineer"]}, och en tydlig felpolicy: tom lista eller felobjekt med orsak. Det ska också framgå att nycklar läses från miljön och aldrig loggas.
Python – det du ska ta med dig
Python-koden visar tre yrkesvanor: läs hemligheter från os.environ, validera JSON innan du använder den och skriv små funktioner som kan testas utan ett riktigt API-anrop. Det är samma mönster som går igen i alla senare agentprojekt.
